Documentation

Get AT Group Chat running locally in under five minutes. This guide covers the static showcase, the bundled app source, configuration, and your first manager-controlled run.

Installation

The npm package exposes the terminal wizard and CLI first. The full source is also bundled in this website folder under app/ and mirrored on GitHub.

npm install -g at-group-chat
at-group-chat setup
at-group-chat doctor

# Source checkout
git clone https://github.com/Felix201209/AT-Group-Chat.git
cd AT-Group-Chat/app
npm install
npm run dev

The local app uses better-sqlite3, which compiles native bindings on install. Ensure you have a C++ compiler available (Xcode Command Line Tools on macOS, build-essential on Linux). The static website itself has no build step.

Setup Wizard

The app includes a real terminal wizard, not just a documentation checklist. Run it and it will show CLI readiness, then guide you through Demo, Real local, Secure local, or Custom setup before writing .env.

# Interactive local setup
npm run setup

# Fast demo setup
npm run setup:mock

# Real CLI setup
npm run setup:real

# Machine-readable setup
npx at-group-chat setup --mock --yes --token auto --hook-token auto --json

# Local npm package smoke
npm pack --dry-run
npm install -g .
at-group-chat setup

Configuration

Create a .env file in app/ when you want to override defaults. No direct OPENAI_API_KEY is required by AT itself; Codex, Claude Code, and Kimi authenticate through their own CLIs.

VariableRequiredDescription
AT_TEAM_API_TOKENNoAPI auth token for browser, HTTP, and MCP callers
AT_TEAM_AGENT_MODENoreal or mock (default: real)
AT_TEAM_CORS_ORIGINNoAllowed browser origin for the local API
AT_TEAM_RATE_LIMIT_MAXNoMax requests per window (default: 600)
AT_TEAM_MAX_BODY_BYTESNoMax request body size (default: 1MB)

API Overview

The API server runs on port 5174 by default. Key endpoints:

Platform

  • GET /api/status — Current project, team, runs, work items, and events
  • GET /api/platform — Setup readiness, CLI availability, auth state, data path, and security fields
  • GET /api/contract — Machine-readable manager contract for external AI agents and IDE tools
  • GET /api/chat — Group chat transcript and participants

Projects

  • GET /api/projects — List all projects
  • POST /api/projects — Create a new project

Agents and Runs

  • GET /api/agents — List configured agents
  • POST /api/agents — Configure an agent role
  • POST /api/runs — Start a manager task
  • POST /api/runs/:id/dispatch — Dispatch a selected role from a run
  • GET /api/runs/:id/events — SSE stream of run events

Work Items

  • GET /api/work-items — List issues, proposals, reviews, decisions, and artifacts
  • POST /api/work-items — Create a work item from chat or UI
  • GET /api/work-items/:id/activity — Linked messages, runs, and events for one work item
  • POST /api/work-items/:id/dispatch — Send a work item to the manager

Authentication

When AT_TEAM_API_TOKEN is set, include the token via one of:

# Header
x-at-token: your-token

# Bearer
Authorization: Bearer your-token

# Query parameter
?token=your-token

Testing

Run the test suite:

# Unit and integration tests
npm test

# Browser E2E tests
npm run test:browser

# Audit checks
npm run audit

# Build verification
npm run build

Tests use Node's built-in test runner for server logic and Playwright for browser automation. No Jest, no Vitest — just native tooling.
