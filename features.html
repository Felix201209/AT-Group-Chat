Features

Everything you need for
AI collaboration.

Not another chat toy: AT gives local agents a manager, a shared transcript, work items, and an audit trail.

01

Manager-Controlled Team

Define roles with system prompts, model settings, thinking level, and permission profiles. The manager interprets the goal, chooses one next agent, then stops.

  • No free discussion and no automatic infinite loops
  • Codex manager and Codex goal reviewer stay as separate sessions
  • Claude Code, Kimi Code, Codex, or any CLI adapter can be configured
  • Every dispatch carries an explicit permission profile
config/agents.yaml 
roles:
  - id: "codex-manager"
    adapter: "codex-server"
    permission: "write-proposed"
  - id: "kimi-ux-review"
    adapter: "kimi"
    focus: "interaction + UI/UX"
  - id: "codex-goal-review"
    adapter: "codex-server"
    focus: "goal satisfaction"
02

Shared Transcript + Events

Server-Sent Events stream run lifecycle changes while the group chat stays focused on human-readable messages.

  • Run timeline shows handoff, approval, output, and failures
  • Chat can hide system events when the user just wants the conversation
  • All agents can read the shared transcript for context
  • Each role still keeps project + role isolated memory
src/events.js 
const source = new EventSource("/api/runs/123/events");

source.addEventListener("message", (e) => {
  const data = JSON.parse(e.data);
  appendToTimeline(data);
});
03

Hardened & Secure

Token-based auth, IP rate limiting, request body size guards, CSP headers, and sanitized error responses make the local service safer to operate.

  • Optional API token via header, Bearer, or query param
  • IP-based rate limiting with window-based pruning
  • Request body size limits prevent DoS
  • CSP headers and sanitized 500 errors
server/http.js 
function requireAuth(req) {
  const token = req.headers["x-at-token"]
    || req.headers["authorization"]
    || req.query.token;
  if (token !== API_TOKEN) {
    throw new ClientError("Unauthorized", 401);
  }
}
04

Work Items

Issues, proposals, reviews, decisions, and artifacts turn the group chat into an actual collaboration platform.

  • Create a work item from the chat
  • Dispatch a work item to the manager
  • Inspect activity threads linked to messages, runs, and events
  • Persist final reviews and decisions instead of losing them in chat scrollback
server/storage.js 
const db = new Database(dbPath);
db.pragma("journal_mode = WAL");
db.pragma("busy_timeout = 5000");

function prepare(sql) {
  let stmt = cache.get(sql);
  if (!stmt) {
    stmt = db.prepare(sql);
    cache.set(sql, stmt);
  }
  return stmt;
}
05

HTTP + MCP Control

Humans can use the UI, while external agents can become the manager by calling the same runtime over HTTP or MCP.

  • team_create_task and team_dispatch_agent for agent-to-agent control
  • POST /api/runs for external managers
  • POST /api/work-items/:id/dispatch for issue-centered review
  • HTTP and MCP share the same runtime, not two separate schedulers
server/runtime.js 
const activeRuns = new Map();
let rolesCache = null;
let rolesCacheAt = 0;

async function runManagerTask({ prompt }) {
  const key = `${run.id}:${roleId}`;

  // dispatch with lock
}
06

Codex Integration

Native WebSocket bridge to OpenAI Codex app-server. Thread-safe resume with automatic recovery from invalid thread states.

  • JSON-RPC over WebSocket for bidirectional comms
  • Thread resume with selective error handling
  • Only "not found" errors reset thread ID
  • All other errors propagate for observability
server/codex.js 
try {
  await client.request("thread/resume", { threadId });
} catch (err) {
  if (/not found|unknown thread/i.test(err.message)) {
    threadId = null;
  } else {
    throw err;
  }
}

How it works

From prompt to outcome
in three steps.

01

Describe your goal

Enter a natural language prompt in the chat. The manager agent interprets your intent and decomposes it into structured tasks.

02

Manager dispatches

Specialist agents reply only when the manager calls them. Reviewers audit outputs, and every decision remains traceable in the shared transcript.

03

Review & iterate

Watch the full event timeline in real time. Edit, retry, or extend the conversation. Every decision is traceable.
