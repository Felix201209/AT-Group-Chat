Architecture

How the pieces fit.

Three local surfaces communicate over predictable ports. The public showcase remains static; the control plane stays local.

Control Console

Vite on port 5173 serves Chat, Work, Team, Platform, and Settings. Hash routing keeps views shareable.

Runtime API

Native Node.js on port 5174 handles REST, SSE, and shared runtime services for both UI and MCP tools.

Codex Server Bridge

WebSocket JSON-RPC on port 5176 talks to Codex app-server, preserving separate manager and goal-review sessions.

Security

Defense in depth.

Security is not a feature you add later. It is built into every layer from day one.

Authentication

Optional bearer token via header, query param, or Authorization header. The Settings security panel shows whether it is enabled.

Rate Limiting

IP-based sliding window with configurable max requests. Prunes stale entries automatically to prevent memory leaks.

CSP & Headers

Content-Security-Policy, X-Content-Type-Options, and CORS origin restrictions keep the attack surface minimal.

Safe Errors

500 responses return generic "Internal server error" messages. Stack traces are logged server-side, never leaked.
